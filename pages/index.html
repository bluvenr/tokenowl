Provider Analytics

Visualize usage distribution and health across all your AI providers. Understand where your money goes at a glance.

One-click sync from CC Switch proxy logs. No manual configuration needed — just connect and start tracking immediately.

◆ Getting Started

Up and running in minutes

Clone, install, and launch. No complicated setup required.

1

Clone the Repository

Clone from GitHub and enter the app directory.

2

Install Dependencies

Install Node.js & Rust toolchains, then run pnpm install.

3

Start Development

Run pnpm tauri dev to launch the app in dev mode with hot reload.

4

Build for Production

Run pnpm tauri build to compile native binaries for your platform.

terminal
# 1. Clone the repository $ git clone https://github.com/bluvenr/tokenowl.git $ cd tokenowl # 2. Install dependencies $ pnpm install # 3. Start development server $ pnpm tauri dev # 4. Build production binaries $ pnpm tauri build
